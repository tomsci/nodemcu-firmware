This module is a bare-bones graphics driver for the SPI-connected ST7789 family of displays.

## st7789.ST7789()
Constructs an `ST7789` instance. Note this does not initialize the display hardware or show anything on the screen, call `init()` on the returned object to do that.

#### Syntax
`st7789.ST7789(options)`

#### Parameters
- `options` A table of device-specific configuration:
    - `spidevice` The SPI device object to use to communicate with the display. Required.
    - `width` Physical width of the display, in pixels. Required.
    - `height` Physical height of the display, in pixels. Required.
    - `dc` The GPIO number of the DC pin. Required.
    - `cs` The GPIO number of the CS pin, if needed by the display. Omit or set to `-1` if chip select is not required.
    - `reset` The GPIO number of the reset pin, if the display has one. Omit or set to `-1` otherwise.
    - `backlight` Set to the GPIO number of the backlight pin, to have the ST7789 module manage the backlight. Omit or set to `-1` if the display doesn't have a backlight pin, or to manage it manually.
    - `inversion` Set to `true` if the display needs color inversion.
    - `rotation` What orientation to start the display in. If not specified, defaults to `st7789.PORTRAIT`. Can be changed later by calling `setRotation`.

#### Returns
An `ST7789` instance.

#### Example
```lua
-- Set SCK_PIN, MOSI_PIN, CS_PIN, DC_PIN, RESET_PIN as appropriate
spimaster = spi.master(1, {
    sclk = SCK_PIN,
    mosi = MOSI_PIN,
    max_transfer_sz = 0,
}, 1) -- 1 means enable DMA
device = spimaster:device({
    mode = 0,
    freq = 40*1000*1000, -- ie 40 MHz
})
display = st7789.ST7789({
    spidevice = device,
    width = 135,
    height = 240,
    cs = CS_PIN,
    dc = DC_PIN,
    reset = RESET_PIN,
})
```

## st7789.color565()
Convert an RGB color into the rgb565 format used by the rest of the APIs.

#### Syntax
`st7789.color565(r, g, b)`

#### Parameters
- `r` Red value, must be an integer between 0 and 255.
- `g` Green value, must be an integer between 0 and 255.
- `b` Blue value, must be an integer between 0 and 255.

#### Returns
An integer in the rgb565 format.

#### Example
```lua
midgray = st7789.rgb565(128, 128, 128)
display:fill(0, 0, 100, 100, midgray)
```

# Color constants
The following color constants are defined:

- `st7789.BLACK`
- `st7789.WHITE`
- `st7789.RED`
- `st7789.GREEN`
- `st7789.BLUE`
- `st7789.CYAN`
- `st7789.MAGENTA`
- `st7789.YELLOW`

# ST7789 display objects

## display:init()
Initialize the display. If a backlight pin was specified during construction, it will be set to on.

#### Syntax
`display:init([color])`

#### Parameters
- `color` The color to initially fill the display with. If not specified, defaults to `st7789.BLACK`.

#### Returns
`nil`

#### Example
```lua
display:init()
```

## display:rect()
Draws a non-filled rectangle using the specified color.

#### Syntax
`display:rect(x, y, w, h, color)`

#### Parameters
- `x`
- `y`
- `w`
- `h`
- `color` Color to use. Must be one of the constants defined above or the result of calling `color565()`.

#### Returns
`nil`

#### Example
```lua
display:rect(0, 0, 100, 50, st7789.GREEN)
```

## display:blit()
Blit a rgb565-format image to the screen.

#### Syntax
`display:blit(buffer, x, y, w, h)`

#### Parameters
- `buffer` The image data to render. Must be in big-endian rgb565 format.
- `x` X-coordinate of where to render the image on screen.
- `y` Y-coordinate of where to render the image on screen.
- `w` Width in pixels of the image.
- `h` Height in pixels of the image.

#### Returns
`nil`

#### Example
```lua
b10 = string.pack(">I2", st7789.BLUE):rep(10)
g10 = string.pack(">I2", st7789.GREEN):rep(10)
patt = string.rep(b10..g10..b10..g10, 10)
display:blit(patt, 0, 0, 40, 10)
```

## display:setBacklight()
Turns on or off the backlight pin, if one was defined in the constructor.

#### Syntax
`display:setBacklight(enable)`

#### Parameters
- `enable` true to turn the backlight on, false to turn it off.

#### Returns
`nil`

#### Example
```lua
display:setBacklight(true)
```

## display:on()
Equivalent to `display:setBacklight(true)`.

#### Syntax

#### Parameters
None

#### Returns
`nil`

## display:off()
Equivalent to `display:setBacklight(false)`.

#### Syntax
`display:off()`

#### Parameters
None

#### Returns
`nil`

## display:setRotation()
Configure the display rotation. The display will need to be redrawn after rotating.

#### Syntax
`display:setRotation(rotation)`

#### Parameters
- `rotation` one of:
    - `st7789.PORTRAIT` Portrait
    - `st7789.LANDSCAPE` Landscape (90 degrees)
    - `st7789.INVERSE_PORTRAIT` Inverse portrait (180 degrees)
    - `st7789.INVERSE_LANDSCAPE` Inverse landscape (270 degrees)

#### Returns
`nil`

#### Example
```lua
display:setRotation(st7789.LANDSCAPE)
```

## display:setSleepMode()
Enter or exit sleep mode. In sleep mode, nothing will be shown on the display and it will use less power. Depending on the device, the contents of the screen may or may not be restored when exiting sleep. Note this API does not alter the backlight state, so for maximum power saving (assuming a backlight pin is defined) call `display:setBacklight(false)` as well as `display:setSleepMode(true)`.

#### Syntax
`display:setSleepMode(enable)`

#### Parameters
- `enable` Set to `true` to enter sleep mode, `false` to exit sleep mode.

#### Returns
`nil`

#### Example
```lua
display:setSleepMode(true)
```
